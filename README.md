# Netmix iOS

Official iOS client for Netmix streaming platform built with Flutter.

## Features
- Native HLS/m3u8 adaptive streaming with media_kit
- Apple Liquid Glass user interface
- Background audio & Picture-in-Picture support
- Automated Cloud IPA compilation via GitHub Actions

## Cloud Build & IPA Download
Go to **Actions** > **Build Netmix iOS IPA** > **Run workflow**.
Download Netmix-iOS-release artifact and sideload via Sideloadly, AltStore, TrollStore, or Scarlet.
